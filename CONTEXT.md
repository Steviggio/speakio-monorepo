# Speakio Domain

This is the root domain context file for the Speakio monorepo. 

As per the `AGENTS.md` guidelines for multi-context repos, please refer to the `CONTEXT-MAP.md` file in this directory to navigate the individual architectural domains and their respective `CONTEXT.md` files (e.g., `apps/web/CONTEXT.md`, `apps/api/CONTEXT.md`).

## Core Concepts
- **Speakio Platform:** A monorepo application containing a Next.js frontend and NestJS backend.
- **Resource Quality:** Backend services evaluate and categorize resources.
- **Auth:** Standardized authentication via Passport across the API.
